# 🚀 RoboCopy Pro – High-Performance File Copy Tool for Windows

RoboCopy Pro is a fast, reliable, and modern Windows file-copy utility that helps you move large files and folders **10× faster** than normal copy-paste.  
It uses multi-threading and robust restartable copy technology to ensure smooth transfers even for huge backups, projects, or media folders.

This repository contains **public releases only** — the source code is private.

---

## ✨ Features

- ⚡ **Multi-Threaded Copying** for high-speed transfers  
- 🔄 **Restartable Mode** that resumes interrupted copies  
- 📁 **Full Folder Copy** including all subdirectories & empty folders  
- 🔁 **Auto-Retry Mechanism** for locked or busy files  
- 📊 **Real-Time Progress Tracking**  
- 🎨 **Clean & Modern User Interface**  
- 💾 Lightweight – No installation needed for users  
- 🛡️ Built on top of Microsoft’s robust `RoboCopy` engine

## 🚀 How to Use

1. Run `RoboCopy Pro.exe`
2. Select **Source Folder**
3. Select **Destination Folder**
4. Choose number of **threads** (default: 4)
5. (Optional) Adjust **Advanced Settings**
6. Click **Start Copy**
7. Monitor progress and logs in real time

---

## ⚙️ Advanced Copy Options

Internally, RoboCopy Pro uses powerful copy flags:

| Option | Description |
|--------|-------------|
| `/E` | Copy all subfolders including empty ones |
| `/Z` | Enable restartable mode |
| `/R:n` | Retry `n` times on failure |
| `/W:n` | Wait `n` seconds between retries |

These ensure safe, efficient, and error-resilient file transfers.
